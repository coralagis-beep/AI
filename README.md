# 🍳 日常食譜小幫手 (Daily Recipe Assistant)

> 「把冰箱裡的食材交給我，幫你想一道簡單的料理。」
> 一款使用繁體中文、具備溫暖生活感的智慧清冰箱食譜應用程式，結合 Google Gemini AI 與各類家庭烹調設備（電鍋、瓦斯爐、壓力鍋、氣炸鍋）的專屬特性，量身打造最適合您的家常美味料理。

## ✨ 主要功能特點

1. **冰箱食材輸入與標籤化管理**
   - 支援逗號、頓號（、）、換行一次貼上多種現有食材。
   - 自動轉換為可單獨刪除的標籤：`[雞胸肉 ×]` `[雞蛋 ×]` `[洋蔥 ×]`。
   - 提供常見生鮮食材一鍵快捷點選（高麗菜、豬肉片、豆腐、番茄等）。

2. **調味料與辛香料庫存專區**
   - **常用高頻辛香調味**：蔥、薑、蒜頭、泡菜、醬油、味醂、鹽麴。
   - **分類篩選**：生鮮辛香料、常備基本調味、風味醬料與特色醃料。
   - **必備常備款一鍵全選**：快速配置蔥薑蒜、醬油、鹽、糖、米酒等家常底料。
   - **自訂香料輸入**：支援加入迷迭香、義大利香料、XO 醬等私人庫存。
   - **LocalStorage 自動記憶**：設定一次即可永久保存於瀏覽器。

3. **四大烹調設備專屬參數**
   - **電鍋**：內鍋放置方式、外鍋加水量（杯數/cc）、是否需要蒸架、跳起後燜煮時間。
   - **瓦斯爐**：火力掌控（大火／中火／小火）、加熱時間、食材入鍋順序、翻炒或加蓋說明。
   - **壓力鍋**：加壓時間、洩壓方式（自然洩壓或手動快速洩壓）、安全容量提醒（不超過 2/3）。
   - **氣炸鍋**：建議烘烤溫度（°C）、烹調時間、是否預熱、中途翻面與搖晃提醒。

4. **精準料理偏好設定**
   - **時間**：不限、15 分鐘內、30 分鐘內、60 分鐘內。
   - **份量**：1 人、2 人、3～4 人、5 人以上。
   - **難度與風味**：簡單、一般、清淡、家常、辣。
   - **「優先消耗快過期食材」開關**（預設開啟），主動提高生鮮用量，落實零浪費。

5. **互動式料理結果與廚房工具**
   - **查看完整步驟／專注烹飪模式**：支援大字體、步驟逐項完成打勾。
   - **隨身廚房計時器**：內建常用 1/3/5/10/15 分鐘快捷設定與倒數提醒鈴聲。
   - **換一道**：不滿意單道菜色時，隨時單獨替換。
   - **我的收藏庫**：一鍵加入書籤並永久保存至側邊抽屜，方便日後重溫。
   - **我還有這些食材**：在結果頁隨時補充新食材，即時更新菜單。

- **AI 引擎**：Google Gemini API (`@google/genai`, `gemini-3.8-flash`)
- **建置工具**：Vite

## 🚀 本地開發與執行

### 1. 安裝相依套件

```bash
npm install
```

### 2. 環境變數設定

複製 `.env.example` 為 `.env`，並填入您的 Gemini API Key：

```env
GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
```

### 3. 啟動開發伺服器

```bash
npm run dev
```

開啟瀏覽器前往 `http://localhost:3000` 即可開始使用。

### 4. 建置生產環境版本

```bash
npm run build
npm run start
```
